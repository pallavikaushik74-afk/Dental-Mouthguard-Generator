Dental Mouthguard Generator

A collaborative group project focused on generating custom-fit dental mouthguards from STL dental scans using Python-based 3D mesh processing techniques. The system combines adaptive normal smoothing, curvature-aware thickness adjustment, boundary refinement, mesh repair, and watertight model generation to produce manufacturable dental guard models.

This project was developed to explore computational geometry, dental CAD workflows, STL mesh processing, and automated medical-device modeling.

Features
STL scan import/export
Adaptive thickness generation
Curvature-based mesh offsetting
Surface smoothing and refinement
Boundary edge stitching
Watertight mesh repair
Fit quality analysis
Interactive 3D visualization
Upper and lower mouthguard generation

Python
